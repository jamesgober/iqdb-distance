# iqdb-distance v1.0.1

A fix release. No API changes.

## Fixed

- **No NaN from finite inputs.** The kernels accumulate in `f32`, so
  components above roughly `1e19` overflow their squares. `Cosine` and
  `DotProduct` could then return NaN, and on x86 that NaN has its sign bit
  set, which `f32::total_cmp` orders below every number: an index would rank
  the vector as the best match. When a fast `Cosine`, `DotProduct`, or
  `Euclidean` result is not finite, that pair is recomputed in `f64`.
  `Cosine` stays in range, `DotProduct` comes back as `±inf` only when the
  true value is beyond `f32`, and `Euclidean` is finite whenever the distance
  itself fits. Ordinary embeddings never reach this path.
- **Cosine range docs.** The range is `[0, 2]` up to rounding; a
  near-identical pair can land a few ULPs below zero.

## Upgrading

Change the version to `1.0.1`. Nothing else is needed.
